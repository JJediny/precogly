{% extends "precogly_auth_base.html" %} {% comment %} Reparents every django-oauth-toolkit page onto Precogly's shell. Its own `base.html` links Bootstrap 2.3.2 from netdna.bootstrapcdn.com, which no longer resolves, so any page inheriting it renders unstyled after waiting on a request that cannot succeed. Overriding this one file fixes all of them at once: `TEMPLATES["DIRS"]` is searched before installed apps, and every template in the package extends this name. Nothing else is needed here. `precogly_auth_base.html` defines the `title` and `content` blocks that django-oauth-toolkit's templates fill, and Django resolves those through the chain — the package's own template becomes the grandchild. The pages that matter in a user's flow — authorize, login, connected applications, and the revoke confirmation — are overridden individually and do not depend on this. This is the safety net for the rest: the application management and device-flow pages, which are reachable only by typing their URL, since MCP clients register through dynamic client registration rather than by hand. They inherit a page that reads plainly rather than one that reads broken. {% endcomment %}
